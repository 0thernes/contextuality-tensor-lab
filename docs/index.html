The native engine executes gates, measurement draws and collapse. A Pauli-basis adapter supplies rotations. Browser draws use a disclosed seeded xorshift32 sampler; the offline stack runner uses Tsotchke QRNG. Mixed-state mode samples a uniform computational-basis ensemble. These are implementation tests, not quantum-hardware observations or a proof from finite sampling.
